# Secure Shell 1.6.0

`secure-shell-fixed-1.6.0.zip` содержит приложение с тремя связанными SQLite-базами:
учётные записи, сохранённые таблицы и исходные документы с доступом только для
администраторов. Включены инструкция DATABASES.md и отчёт о 120 успешных тестах.

Архив содержит исходники и скрипт сборки Windows EXE. Для запуска распакуйте весь
архив и откройте Запустить.bat; необходимы Python 3.10+ и интернет для сборки.
Готовый EXE не включён, сборка Windows в этой поставке не проверялась.

SHA256 исходного архива приведён в SHA256SUMS.
