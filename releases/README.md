# Вуаль 1.7.0

[Скачать архив](https://github.com/pavelkozlov2004-sketch/secure-shell/raw/refs/tags/v1.7.0/releases/vual-1.7.0.zip)

Включены центральный HTTPS-сервер учётных записей, автоматическое обновление
клиентского users.db, статусы подключения с цветами и восстановление пользователей.
Три базы данных хранят аккаунты, преобразованные таблицы и исходные документы.
В архиве есть три небольших примера JSON, README.md с настройкой сервера и клиентов,
DATABASES.md и отчёт о 194 успешных тестах.

Архив содержит исходники и Windows-скрипты сборки и запуска. Для сборки нужны
Python 3.10+ и интернет. Готовые EXE не включены; сборка Windows и работа в
физической локальной сети не проверялись. Проверки HTTPS выполнены на loopback
с независимыми базами сервера и клиентов.

SHA-256 исходного архива приведён в SHA256SUMS.
